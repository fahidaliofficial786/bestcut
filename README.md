# BEST CUT | Barber & Salon Manchester

Modern web application for **BEST CUT**, premier barber and salon located at 317 Littleton Rd, Manchester M7 3TA.

## Features

- ✂️ **Modern Responsive UI**: Built with React 19, TanStack Start, and Tailwind CSS.
- 💈 **Service Showcase & Pricing**: Comprehensive service menu with clear pricing.
- 📅 **Online Booking & Contact**: Fast contact and booking flow with salon working hours.
- 📸 **Gallery**: Showcase of haircuts, fades, and beard styling.
- ⚡ **Blazing Fast Performance**: SSR and client-side routing powered by TanStack Start and Vite.

## Tech Stack

- **Framework**: TanStack Start / TanStack Router
- **UI Library**: React 19
- **Styling**: Tailwind CSS v4, Lucide Icons, Radix UI primitives
- **Bundler**: Vite

## Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm or bun or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/fahidaliofficial786/bestcut.git

# Navigate into project directory
cd bestcut

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
